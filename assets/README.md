# Filament Finder illustrations

Four transparent PNGs were generated with the built-in image-generation tool for this
interface update. They are original illustrative assets, not product photographs or
proof of material properties. No provider API key is required to display them.

| File | Where it is used |
|---|---|
| logo.png | Header brand mark and browser favicon |
| spool_teal.png | Empty state and generic filament illustration |
| spool_carbon.png | PLA-CF illustration |
| spool_flexible.png | TPU illustration |

`MATERIAL_ART` in app.py maps supported materials to the pictures. All material
identities are also shown as text. The generic teal illustration is intentionally
shared; different polymer types do not imply particular commercially available colors.

## Generation prompts

### spool_teal.png

Use case: illustration-story. Create a single isolated 3D printer filament spool illustration for a friendly web application called Filament Finder. Three-quarter front view, upright spool with warm off-white circular flanges, a central hole, and mint teal filament wound neatly around its core. Charcoal ink contours, subtle hand-drawn pencil texture and restrained gray hatching, softly organic yet clean professional editorial line art. Match a white paper wireframe website with mint buttons. No text, no letters, no labels, no background props, no ground shadow outside the object. Entire object centered with generous transparent margins. Transparent background. This generic spool is illustrative, not an actual product.
